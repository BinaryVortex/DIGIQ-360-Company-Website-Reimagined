# DIGIQ 360 — Company Website Reimagined

A modern reimagining of the DIGIQ 360 company website, created with a focus on clean presentation, responsive design, and a polished digital experience.

## 🌐 Live Demo

**Live Website:**  
https://binaryvortex.github.io/DIGIQ-360-Company-Website-Reimagined/

## 📌 About the Project

**DIGIQ 360 Company Website Reimagined** is a front-end redesign/reimplementation of a company website concept for DIGIQ 360.

The project focuses on presenting company information through a modern, visually engaging interface while keeping the overall experience simple, responsive, and easy to navigate.

## ✨ Features

- Modern company website layout
- Clean and professional UI
- Responsive web design
- Structured company information
- Smooth navigation between website sections
- Visual-first presentation
- Lightweight front-end implementation
- Easy to run locally without a complex setup

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic content
- **CSS3** — Styling, layout, responsiveness, and visual design
- **JavaScript** — Client-side interactions and functionality

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/BinaryVortex/DIGIQ-360-Company-Website-Reimagined.git
```

### 2. Navigate to the Project

```bash
cd DIGIQ-360-Company-Website-Reimagined
```

### 3. Open the Website

Open `digiq360.html` directly in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## 💻 Running with VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `digiq360.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. The website will open in your default browser.

## 🎨 Design Goals

The website was designed around a few key principles:

- **Simplicity** — Keep the interface clean and easy to understand.
- **Modern Design** — Use contemporary web design patterns to create a professional appearance.
- **Responsiveness** — Ensure the experience works across different screen sizes.
- **Clarity** — Present company information in a structured and readable way.
- **User Experience** — Make navigation intuitive and visually engaging.

## 📱 Responsive Design

The website is intended to provide a consistent experience across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile devices
- 📟 Tablet-sized screens

## 🎯 Purpose

This project demonstrates how a traditional company website can be reimagined with a modern front-end approach, focusing on visual hierarchy, responsive layouts, and a polished user experience.

It can also serve as a portfolio project demonstrating front-end development and UI implementation skills.
